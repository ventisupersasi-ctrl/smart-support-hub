# Руководство пользователя

## Назначение
Smart Support Hub — учебный прототип для учёта внедрений, инцидентов и сопровождения ПО. Используйте только вымышленные данные.

## Как зарегистрировать инцидент
Откройте «Инциденты», введите описание, выберите приоритет и нажмите «Зарегистрировать». Переведите запись в работу или нажмите «Решить». Фильтр показывает выбранный статус. SLA рассчитывается по приоритету и времени регистрации.

## Как создать заявку на изменение
Откройте «Заявки», заполните описание, вид, статус и целевую версию (например, v1.1.0). Нажмите «Добавить заявку». Статус можно менять в таблице.

## Внедрения и релизы
Заполните форму внедрения, указав число выполненных и общее число задач. Этап меняется в реестре. В «Релизах» выберите patch/minor/major для расчёта номера следующего выпуска.

## Куда обратиться
Сообщите о проблеме через вкладку Issues репозитория: шаги, ожидаемый и фактический результат, снимок экрана без личных данных.

Данные сохраняются в localStorage текущего браузера и адреса сайта. Очистка хранилища удаляет пользовательские записи. Общего сервера и синхронизации нет.

В v1.1.0 доступен поиск инцидентов и кнопка «Скачать CSV» в реестре заявок.
