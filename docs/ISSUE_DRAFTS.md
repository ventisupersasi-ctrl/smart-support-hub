# Предложения для пользовательской проверки
Это замечания внутренней проверки, а не полученные отзывы. Перед сдачей дайте сайт одногруппнику, зафиксируйте два его фактических замечания в GitHub Issues и внесите нужные исправления.

## 1. Поиск инцидентов
В v1.0.0 доступен только фильтр статуса. Добавить поиск по ID и описанию. Поиск и фильтр должны работать совместно. Реализовано в v1.1.0.

## 2. Выгрузка заявок
В v1.0.0 реестр нельзя выгрузить. Добавить кнопку CSV. Файл должен содержать заголовки и записи. Реализовано в v1.1.0.
