# Smart Support Hub

Учебная веб-платформа внедрения, эксплуатации и сопровождения ПО. HTML, CSS, JavaScript, localStorage, Chart.js (CDN; автономная отрисовка при отсутствии CDN).

## Запуск

```sh
python -m http.server 8000
```

Откройте http://localhost:8000/. Можно использовать Live Server в VS Code. Интернет нужен для Chart.js, при его недоступности работает резервная отрисовка Canvas.

## Возможности
- Панель: 4 KPI, 2 диаграммы.
- Внедрения: реестр, добавление, этап, готовность.
- Инциденты: регистрация, статусы, SLA 4/8/24/72 часа, фильтр.
- Заявки: четыре вида сопровождения, статус, целевая версия.
- Релизы: история, SemVer.
- Тёмная/светлая тема и сохранение данных.

[Руководство](docs/USER_GUIDE.md) · [История изменений](CHANGELOG.md)

Данные вымышленные, хранятся только в браузере. Нет авторизации или общего сервера. Для публикации используйте GitHub Pages из ветки main, корень репозитория.
